# Visual restyle direction

This app now follows the private Property Manager marketing site’s visual language without sharing implementation code.

- **Tone:** quiet operational confidence; an editorial ledger made contemporary.
- **Typography:** DM Sans for UI/body, Fraunces italic for brand and month emphasis, DM Mono for compact labels.
- **Palette:** warm paper `#F6F6F1`, botanical ink `#17231F`, lime `#D9EF85`, amber `#F4B96A`, muted sage `#65736D`.
- **Surfaces:** warm white cards, thin sage rules, restrained 3–5px radii, subtle lifted shadows only where useful.
- **Hierarchy:** generous breathing room, compact mono metadata, serif emphasis for human/date context, direct ink/lime primary actions.
- **Responsive behavior:** existing shared components and mobile navigation remain intact; only visual tokens and presentation classes change.
- **Accessibility:** contrast remains legible, focus rings are visible, and motion is limited to existing interaction feedback.

The marketing site remains inspiration only; this app keeps its existing routes, data, server actions, auth, demo, and backend contracts.
