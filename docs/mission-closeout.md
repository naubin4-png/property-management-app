# Mission Closeout Checklist

- [ ] Working tree is clean and on the latest `origin/main`.
- [ ] `pnpm lint`, `pnpm test`, and `pnpm build` pass.
- [ ] `pnpm prisma migrate status` is clean.
- [ ] The deployed SHA is recorded under Evidence in the mission file.
- [ ] The affected production route is verified.
- [ ] The mission branch is deleted locally and remotely.
- [ ] The mission Status line is set to `Accepted`, `Accepted-with-deferrals`, or `Blocked`.
